# 13번 저택 — 탈출 기록

불이 꺼진 저택을 조사하고 단서를 모아 현관문을 여는 한국어 포인트 앤 클릭 공포 게임입니다.

## 실행

index.html을 브라우저에서 열면 바로 플레이할 수 있습니다. 설치 과정이나 외부 라이브러리, 서버가 필요하지 않습니다. GitHub Pages를 켜면 웹사이트 주소로도 플레이할 수 있습니다.

## 플레이

- 장면 위에 표시되는 조사 지점을 눌러 물건과 단서를 찾습니다.
- 방 사이의 문이나 아래쪽 발견한 공간 버튼으로 이동합니다.
- 소지품과 발견한 단서는 조사 기록에 자동으로 정리됩니다.
- 진행 상황은 브라우저의 로컬 저장소에 자동 저장됩니다.
- 잠금 숫자는 화면 키패드 또는 키보드 숫자로 입력할 수 있습니다.

처음부터 다시 시작하면 저장된 진행 상황을 덮어씁니다. 효과음은 오른쪽 위 음표 버튼으로 켜거나 끌 수 있습니다.

## 기술

HTML, CSS, 바닐라 JavaScript로 만든 정적 웹앱입니다. 게임 진행과 그림은 브라우저 안에서 처리되며 외부 이미지나 서비스에 의존하지 않습니다.
