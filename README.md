# 13번 저택 — 탈출 기록

불이 꺼진 저택을 조사하고 단서를 모아 현관문을 여는 한국어 포인트 앤 클릭 공포 게임입니다. 조사할수록 저택의 기척이 강해지고, 그림자와 발소리, 속삭임이 나타납니다.

## 실행

index.html을 브라우저에서 열면 바로 플레이할 수 있습니다. 설치 과정이나 외부 라이브러리, 서버가 필요하지 않습니다. GitHub Pages가 설정되어 있으면 웹사이트 주소로도 플레이할 수 있습니다.

## 플레이

- 장면 위의 지점을 눌러 물건과 단서를 찾습니다.
- 방 사이의 문이나 발견한 공간 목록으로 이동합니다.
- 저택의 기척 수치가 오르면 유령이 나타나거나 발소리가 가까워집니다.
- 소지품과 단서는 조사 기록에 자동으로 정리되고, 진행 상황은 이 브라우저에 저장됩니다.
- 암호는 화면 키패드 또는 키보드 숫자로 입력합니다.
- 오른쪽 위의 소리 버튼을 켜면 낮은 배경음과 긴장 효과음이 들립니다. 소리 없이도 플레이할 수 있습니다.

## 퍼즐 흐름

현관 홀 초상화의 숫자로 서재 금고를 열고 지하실 열쇠를 찾습니다. 주방의 퓨즈로 보일러실 전원을 복구한 뒤, 편지에서 발견한 날짜를 현관에 입력해 탈출하세요. 힌트 버튼이 막힌 구간을 알려줍니다.

## 기술

HTML, CSS, 바닐라 JavaScript로 만든 정적 웹앱입니다. 게임 화면과 소리는 브라우저 안에서 처리합니다. 외부 이미지나 서비스는 필요하지 않습니다.
